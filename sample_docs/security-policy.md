# Security policy

This is a fictional handbook written as sample data for the RAG agent.

Every employee account must use multi-factor authentication with a hardware security key. Text message codes are not an accepted second factor.

Passwords are stored only in the company password manager. They must be at least 16 characters long and are never shared over chat or email.

Laptops use full-disk encryption and lock automatically after five minutes of inactivity. A lost or stolen device must be reported to the security team within one hour so it can be wiped remotely.

Access to production systems follows the principle of least privilege. Elevated access is granted for a maximum of eight hours through the access request tool and every session is logged.

Customer data must not be copied to personal devices or to services that the security team has not approved.
